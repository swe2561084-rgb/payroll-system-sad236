# ADR-001: Цалин тооцооллын системийг вэбд суурилсан гурван түвшинт архитектураар хэрэгжүүлэх

**Төлөв:** Баталсан

## Нөхцөл
- Ажилтан гар утаснаас цалингийн хуудсаа харна (Chrome, Safari).
- Цалин, банкны дансны мэдээлэл нууц: AES-256, эрхээр хандалт, HTTPS.
- Сар бүрийн бодолтын үед 500 ажилтны бодолт ≤ 10 секунд; ажиллагаа ≥ 99.5%.
- Бодолтын томьёо нэг газарт байх ёстой (нарийвчлал, хяналт).

## Шийдвэр
React вэб (responsive) + Node.js REST API + PostgreSQL. Цалин бодох логикийг сервер талд (`src/payroll.js`) хэрэгжүүлнэ. Өдөр бүр нөөцлөлт хийнэ.

## Харьцуулсан хувилбар
Desktop програм + төв өгөгдлийн сан (2 түвшин): жигнэсэн оноо 2.50, гар утас дэмжихгүй, шинэчлэлт бүрийг компьютер болгонд суулгана.

## Үр дагавар
- (+) Гар утас дэмжинэ, нэг газар шинэчилнэ, томьёо нэг газарт.
- (+) Эрхийн хяналт, шифрлэлтийг сервер талд төвлөрүүлнэ.
- (−) Интернэт тасарвал системд хандах боломжгүй.
- (−) Сервер, нөөцлөлтийг хариуцах хүн хэрэгтэй.
