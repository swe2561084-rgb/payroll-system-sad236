# Цалин тооцооллын систем

![CI](../../actions/workflows/ci.yml/badge.svg)

SAD236 · Системийн шинжилгээ ба зохиомж · Лаборатори 12 (Архитектурын зохиомж ба CI).

## Архитектур
Вэбд суурилсан гурван түвшинт архитектур: **React вэб** (танилцуулга) → **Node.js REST API** (хэрэглээ) → **PostgreSQL** (өгөгдөл).
Шийдвэрийн үндэслэлийг [docs/ADR-001.md](docs/ADR-001.md)-ээс үзнэ.

## Хавтасны бүтэц
| Хавтас | Агуулга |
|---|---|
| `docs/` | Диаграмм, ADR |
| `db/` | PostgreSQL схем (`schema.sql`) |
| `src/` | Цалин бодох логик (`payroll.js`) |
| `test/` | Нэгжийн тест |
| `.github/workflows/` | GitHub Actions CI (`ci.yml`) |

## Локалд ажиллуулах
```bash
npm ci
npm test
```

## Салбар ба pull request
`main` салбар хамгаалалттай. Ажлыг `feature/...` салбар дээр хийж, pull request-ээр нэгтгэнэ. CI ногоон болсны дараа л нэгтгэнэ.
